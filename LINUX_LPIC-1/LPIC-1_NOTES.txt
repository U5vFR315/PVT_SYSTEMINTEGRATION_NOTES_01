# Linux dmesg
-- Zweck = Zeigt Meldungen des Linux-Kernels
-- Quelle = Kernel-Ringbuffer im Arbeitsspeicher
-- Inhalt = Hardware, Treiber, USB, Netzwerk, Festplatten, Kernel-Fehler
-- Nützlich für = Treiber-, Hardware-, USB-, Festplatten- und Boot-Probleme

# sudo lshw       
-- Detaillierte Hardware-Infos, sudo lshw -short = kompakte Übersicht

# /proc
-- Zweck = Virtuelles Linux-Dateisystem für Live-Infos über Prozesse, Kernel und Hardware
-- Inhalt = Prozessordner wie /proc/<PID> sowie Dateien wie cpuinfo, meminfo und mounts
-- Virtuell = Daten liegen nicht normal auf der Festplatte, sondern werden vom Kernel beim Lesen erzeugt
-- Nutzen = System analysieren, Prozesse prüfen und Kernel-/Systemzustand auslesen

# /proc/sys
-- Zweck = Schnittstelle zu laufenden Kernel-Einstellungen
-- Inhalt = Parameter für Netzwerk, Speicher, Prozesse, Sicherheit usw.
-- Nutzen = Kernel-Verhalten anzeigen und teilweise direkt ändern
-- Beispiel = /proc/sys/net/ipv4/ip_forward → steuert IP-Forwarding
-- Hinweis = Viele Werte können komfortabler mit `sysctl` gelesen/geändert werden
