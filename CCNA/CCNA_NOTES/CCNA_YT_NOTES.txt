CCNA – ACL WILDCARD BERECHNUNG
========================================

WEG 1: WILDCARD GEGEBEN → IP-BEREICH BERECHNEN
----------------------------------------

BEISPIEL:
IP:        10.120.160.0
Wildcard:  0.0.7.255

1. SUBNETZMASKE BERECHNEN
   255 - 7 = 248

2. BLOCKGRÖSSE BERECHNEN
   256 - 248 = 8

3. IP-BEREICH BESTIMMEN
   Start: 160
   Ende:  160 + 8 - 1 = 167

ERGEBNIS:
10.120.160.0 – 10.120.167.255


WEG 2: IP-ADRESSEN GEGEBEN → WILDCARD BERECHNEN
----------------------------------------

BEISPIEL:
192.168.16.0
192.168.17.0
192.168.18.0
192.168.19.0

1. BLOCKGRÖSSE BESTIMMEN
   16, 17, 18, 19 = 4 Werte
   Blockgröße = 4

2. SUBNETZMASKE BERECHNEN
   256 - 4 = 252

3. WILDCARD BERECHNEN
   255 - 252 = 3

ERGEBNIS:
IP:        192.168.16.0
Wildcard:  0.0.3.255

ACL:
access-list 10 permit 192.168.16.0 0.0.3.255


========================================
MERKSÄTZE
========================================

WEG 1: Wildcard → IP-Bereich
255 - Wildcard = Subnetzmaske
256 - Subnetzmaske = Blockgröße

WEG 2: IP-Bereich → Wildcard
256 - Blockgröße = Subnetzmaske
255 - Subnetzmaske = Wildcard

MÖGLICHE BLOCKGRÖSSEN:
1, 2, 4, 8, 16, 32, 64, 128, 256

WICHTIG:
- Gilt für normale, zusammenhängende Wildcards.
- Die Blöcke müssen korrekt ausgerichtet sein.
- Bei nicht zusammenhängenden Wildcards:
  Binärmethode verwenden.

# COMPUTER NETWORK
-- A Network is a digital communications network, which allows nodes to share resources
-- Nodes: Router, Switch, Firewall, Server, Client

### Cisco Switch Commands ###

# enable
-- Purpose = enter privileged EXEC mode, Prompt Change = Switch> → Switch#

# show mac address-table
-- Purpose = show learned MAC addresses, Output Meaning = MAC Address → VLAN → Switch Port

# Multilayer Switch
-- Funktion = Kombiniert Layer-2-Switching und Layer-3-Routing
-- Layer 2 = Leitet Frames anhand von MAC-Adressen weiter
-- Layer 3 = Routet Pakete zwischen verschiedenen VLANs und IP-Netzen
-- Inter-VLAN Routing = Erfolgt über SVIs direkt auf dem Switch
-- Vorteil = Schneller als Router-on-a-Stick, da Routing hardwarebasiert erfolgt
-- Voraussetzung = `ip routing` aktivieren und VLAN-Interfaces konfigurieren

# Tier Architecture
-- 1-Tier = Alle Geräte hängen an einem zentralen Switch; einfach, aber wenig skalierbar
-- 2-Tier = Access Layer verbindet Endgeräte; Distribution und Core sind kombiniert
-- 3-Tier = Access, Distribution und Core sind getrennte Schichten
-- Access Layer = Anschluss von PCs, Druckern und Access Points
-- Distribution Layer = Routing zwischen VLANs und Anwendung von Richtlinien
-- Core Layer = Schnelle Verbindung zwischen den Netzwerkbereichen
-- Multilayer Switch = Übernimmt Switching auf Layer 2 und Routing auf Layer 3

# Spine/Leaf (Clos) Design
-- Leaf Switches = Verbinden Server, Storage und andere Endgeräte
-- Spine Switches = Verbinden alle Leaf Switches untereinander
-- Clos Fabric = Jeder Leaf ist mit jedem Spine verbunden
-- East-West Traffic = Optimiert für Server-zu-Server-Kommunikation
-- ECMP = Mehrere gleichwertige Pfade werden parallel genutzt
-- Vorteil = Hohe Skalierbarkeit, Redundanz und vorhersehbare Latenz

# Underlay
-- Underlay = Physisches Layer-3-Netz zwischen Leaf und Spine
-- Aufgabe = IP-Erreichbarkeit zwischen allen Netzwerkgeräten sicherstellen
-- Protokolle = Häufig BGP, OSPF oder IS-IS
-- Transport = Trägt den Overlay-Traffic durch die Fabric

# Overlay,
-- Overlay = Virtuelle Netzwerke über dem Underlay
-- Technik = Häufig VXLAN
-- Control Plane = Meist BGP EVPN
-- Funktion = Mandantentrennung, Layer-2-Erweiterung und virtuelle Segmente
-- VTEP = Kapselt und entkapselt VXLAN-Traffic auf den Leaf Switches
